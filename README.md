### Portfolio

В этом репозитории собраны мои главные проекты для демонстрации моих навыков. Каждый проект находится в отдельной папке и снабжен подробной инструкцией по запуску.

## Список проектов

### 1. [Raglo_parser.ru (Telegram-бот + парсер)](Parser_raglo.ru/)
Многопоточный парсер интернет-магазина, интегрированный с Telegram-ботом управления.
* **Стек технологий:** 
- C#/.NET 10
- Telegram.Bot
- EF Core
- PostgreSQL
- HtmlAgilityPack

* **Ключевые функции:** 
- Параллельная загрузка
- Парсинг по расписанию
- Сохранение состояния пользователя в JSON
- Выгрузка отчетов в Excel

* [Перейти к подробному README проекта](Parser_raglo.ru/README.md)

### 2. [ReferralBot (Реферальный бот)](ReferralBot/)
Бот с реферальной системой под капотом. Представляет собой просто удобную среду для реализации реферальной системы
* **Стек технологий:** 
- C#/.NET 10
- Telegram.Bot
- EF Core
- PostgreSQL

* [Перейти к подробному README проекта](ReferralBot/README.md)
